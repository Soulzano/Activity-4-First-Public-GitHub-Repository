# Risk Mitigation & Technical Constraints
## Core Technical Risks
*   **Highest Risk Feature:** Google Account Linking
*   **The Hazard:** Difficulty with implementing the feature due to having no experience with setting up the system
## The Pivot Strategy
If our primary implementation for this feature fails or takes too long, our backup plan is to:
*   Have all the in-app features linked together instead, without using Google
*   There is no need for a placeholder since it's a non-essential feature and is optional
